# 100 Days of Learning

This repository records what I learn every day for 100 days.

Rules
- One post per day (minimum: short summary + 1 thing I learned).
- Posts are written in Markdown and stored under /days.
- Each post should include a short TL;DR and links/references.
- Use zero-padded day numbers: days/day-01-title.md

Goals
- Build a habit of daily learning and writing.
- Create a searchable reference for future me.
- Share progress publicly (optional).

Structure
- days/: daily Markdown posts (day-01-topic.md)
- assets/: images and diagrams
- DAY_TEMPLATE.md: template to copy each day

How to contribute
- I will add my daily posts.
- If you want to add suggestions or resources, open an issue or PR.
